# `BasicsTransformerLM` (总模型)：理论知识

## 1\. 作用与目的

`BasicsTransformerLM` 是我们整个项目的“总容器” (main container) 和最终成品。它本身不包含复杂的*新*逻辑，它的**唯一**工作就是**按顺序**把我们之前构建的所有“零件”模块连接起来，形成一个完整的、端到端 (end-to-end) 的语言模型。

它代表了讲义中的 **图 1 (Figure 1)**——“Decoder-Only” Transformer 的高层蓝图。

## 2\. 架构原理 (数据流)

一个 `BasicsTransformerLM` 的**数据流**（即 `forward` 方法）严格遵循以下顺序：

1.  **输入 (Token IDs)**：

      * 形状 `(B, S)`，例如 `(32, 256)`。
      * 这是 `get_batch` 传来的整数 Token ID。

2.  **`Token Embedding` (笔记 3)**：

      * `self.token_embeddings`
      * 形状 `(B, S)` -\> `(B, S, D_m)`，例如 `(32, 256, 512)`。
      * 将整数 ID 转换为 512 维的浮点数向量。

3.  **`TransformerBlock` 堆叠 (Stack)**：

      * `self.layers` (一个 `nn.ModuleList`)
      * 这是一个 `for` 循环，将 `(B, S, D_m)` 的张量**依次**穿过 `num_layers` (例如 4) 个 `TransformerBlock`。
      * 形状 `(B, S, D_m)` -\> `Block 0` -\> `(B, S, D_m)` -\> `Block 1` -\> `...` -\> `(B, S, D_m)`。

4.  **`Norm` (最终归一化)** (笔记 4)：

      * `self.ln_final`
      * 形状 `(B, S, D_m)` -\> `(B, S, D_m)`。
      * 在送入最后一层之前，对**最后一个** `TransformerBlock` 的输出进行**最后一次** `RMSNorm` 归一化。这对应图 1 中的 `Norm` 层。

5.  **`Linear (Output Embedding)` (笔记 2)**：

      * `self.lm_head` (Language Model Head)
      * 形状 `(B, S, D_m)` -\> `(B, S, vocab_size)`，例如 `(32, 256, 512)` -\> `(32, 256, 10000)`。
      * 这是模型的**最后一层** `Linear`，它将 512 维的“思考”向量**上投影** (up-project) 到 10000 维（`vocab_size`）的空间。这对应图 1 中的 `Linear` 层。

6.  **输出 (Logits)**：

      * 形状 `(B, S, vocab_size)`，例如 `(32, 256, 10000)`。
      * 这个张量就是\*\*“Logits”\*\*（原始分数）。
      * `output[b, t, :]` (一个 10000 维的向量) 代表模型在批次 `b`、位置 `t` 预测的**下一个**词的**原始分数**。
      * **注意**：`softmax` **不**在 `BasicsTransformerLM` 内部。它将在**之后**被 `CrossEntropyLoss`（训练时）或 `generate` 函数（推理时）调用。

## 3\. 讲义中的关键要求与约束

  * **Problem (transformer\_lm)**：必须实现 `TransformerLM` 模块。
  * **组件**: 必须使用 `Embedding`、`nn.ModuleList`、`TransformerBlock`、`RMSNorm` 和 `Linear` (LM Head)。
  * **参数**: `__init__` 必须接收 `vocab_size`、`context_length` (用于 RoPE)、`num_layers`, 等所有子模块需要的参数。
  * **RoPE 共享**：讲义 §3.5.3 建议可以（为了优化）让所有层共享**一个** `RoPE` 实例。“优秀代码” 正是这么做的。

```python
# (位于 hw1-basics/scripts/model.py)
# ... (依赖我们之前实现的所有模块: Embedding, TransformerBlock, RMSNorm, Linear, RotaryEmbedding)

class BasicsTransformerLM(nn.Module):
    """A Transformer language model."""

    def __init__(
        self,
        vocab_size: int,     # 10000
        context_length: int, # 256
        d_model: int,        # 512
        num_layers: int,     # 4
        num_heads: int,      # 16
        d_ff: int,           # 1344
        rope_theta: float,   # 10000.0
    ):
        # ... (省略 config 的保存) ...
        super().__init__()
        self.vocab_size = vocab_size
        self.context_length = context_length
        self.d_model = d_model
        
        # 1. 初始化 Token Embedding 层 (笔记 3)
        # 含义: 创建一个 (vocab_size, d_model) 即 (10000, 512) 的查找表。
        self.token_embeddings = Embedding(vocab_size, d_model)
        
        # 2. 初始化 RoPE 模块 (笔记 6)
        # 含义: 创建 *一个* RoPE 实例。
        #   d_head (dim) = 512 / 16 = 32。
        #   这个实例将被 *共享* 并传递给 *所有* TransformerBlock。
        d_head = d_model // num_heads
        self.positional_encoder = RotaryEmbedding(
            context_length=context_length,
            dim=d_head,
            theta=rope_theta
        )
        
        # 3. 初始化 TransformerBlock 堆叠 (Stack)
        # 含义: 创建一个 nn.ModuleList，
        #   它包含 num_layers (4) 个 TransformerBlock 实例。
        #   这是一个 Python 列表，但 nn.ModuleList 会确保 PyTorch 能“看到”
        #   并正确管理列表中的所有模块（例如移动到 GPU、注册参数等）。
        self.layers = nn.ModuleList(
            [
                TransformerBlock(
                    d_model=d_model,
                    num_heads=num_heads,
                    d_ff=d_ff,
                    positional_encoder=self.positional_encoder, # 共享同一个 RoPE
                )
                for _ in range(num_layers) # 循环 4 次，创建 4 个 Block
            ]
        )
        
        # 4. 初始化最终的 RMSNorm (笔记 4)
        # 含义: 创建 *一个* 最终的 RMSNorm 实例。
        #   这对应图 1 中、Softmax 之前的那个 "Norm"。
        self.ln_final = RMSNorm(d_model)
        
        # 5. 初始化 LM Head (笔记 2)
        # 含义: 创建 *一个* 最终的 Linear 层 (语言模型头)。
        #   它将 512 维 映射到 10000 维 (vocab_size)。
        #   这对应图 1 中的 "Linear (Output Embedding)"。
        self.lm_head = Linear(d_model, vocab_size)

    def forward(self, x: Int[Tensor, " ... sequence_length"]) -> Float[Tensor, " ... sequence_length vocab_size"]:
        
        # 形状: (B, S) -> (32, 256)
        # 含义: (即输入 x)
        #   32 (B): 32 个序列 (批次大小)。
        #   256 (S): 每个序列 256 个 Token ID (整数)。
        
        # --- 步骤 1: 词嵌入 ---
        # 形状: (32, 256) -> (32, 256, 512)
        # 含义: (B, S) -> (B, S, D_m)
        #   32 (B): 32 个序列。
        #   256 (S): 256 个 Token。
        #   512 (D_m): 每个 Token ID 被转换成 512 维的浮点数向量。
        x = self.token_embeddings(x)

        # --- 步骤 2: 循环通过 TransformerBlock ---
        for layer in self.layers:
            # 形状: (32, 256, 512) -> (32, 256, 512)
            # 含义:
            #   将 (B, S, D_m) 张量送入一个 TransformerBlock，
            #   输出一个形状相同但内容更丰富的 (B, S, D_m) 张量。
            #   这个循环执行 num_layers (4) 次。
            #   x (第1次) = Block_0(x_emb)
            #   x (第2次) = Block_1(Block_0(x_emb))
            #   ...
            x = layer(x)

        # --- 步骤 3: 最终归一化 ---
        # 形状: (32, 256, 512) -> (32, 256, 512)
        # 含义:
        #   形状不变。
        #   对 4 个 Block 的最终输出进行 *最后一次* RMSNorm 归一化。
        x = self.ln_final(x)

        # --- 步骤 4: LM Head (输出投影) ---
        # 形状: (32, 256, 512) -> (32, 256, 10000)
        # 含义: (B, S, D_m) -> (B, S, vocab_size)
        #   32 (B): 32 个序列。
        #   256 (S): 256 个 Token。
        #   10000 (vocab_size):
        #     将 512 维的“最终思考”向量，通过 Linear 层投影到 10000 维。
        #     这 10000 个数就是预测 *下一个* 词的原始分数 (Logits)。
        return self.lm_head(x)
```
